# 核心信条

## 1. 简单优于完备

这是一个个人项目，不需要企业级架构。每个新增功能只需一个 .vue 文件。拒绝引入复杂的状态管理、路由守卫、中间件层。

## 2. 零运维

无后端、无数据库、无 CI/CD 复杂流程。Vercel 自动部署，静态资源 CDN 分发。任何需要服务器的方案都应被拒绝。

## 3. 视觉优先

目标用户是家人朋友，体验比代码质量重要。动画、过渡、色彩搭配是核心关注点，不是附加品。

## 4. 偏好无聊的技术

Vue 3 + Tailwind + DaisyUI 是稳定的组合。不引入实验性框架或冷门库。依赖越少越好。

## 5. 文件即路由

每个页面是独立的 .vue 文件，通过文件系统自动注册路由。不手动维护路由配置。

## 6. 渐进增强

页面先保证静态内容可读，动画和交互作为增强层。不依赖 JavaScript 就能看到基本内容。
