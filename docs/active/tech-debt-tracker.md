# 技术债务追踪

智能体在修改某个领域前，应先查看该领域是否有已知债务。完成任务后发现新的债务，应记录到此文件。

| 编号 | 领域  | 问题描述                                                                                                                  | 优先级 | 记录日期   | Owner  | 关联计划                             |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------------------- | ------ | ---------- | ------ | ------------------------------------ |
| TD1  | types | TypeScript 6 的 CLI 试验已通过，但缺少 Vue - Official/Volar 的人工编辑器验证；目前保留 TypeScript 5.9.3。                 | 中     | 2026-09-15 | ORPHAN | [1.1.0 依赖升级](./1.1.0/release.md) |
| TD2  | build | npm 审计仍有 4 个 high、1 个 moderate、1 个 low 告警，均为构建工具链的传递依赖；等待 unplugin 生态与 Vite/less 上游更新。 | 高     | 2026-09-15 | ORPHAN | [1.1.0 依赖升级](./1.1.0/release.md) |

## 优先级含义

- **紧急**：阻碍智能体有效工作或导致生产事故。应优先处理。
- **高**：降低质量评分，应在本迭代解决。遇到时应顺手修复。
- **中**：已知缺口，已有改进计划。按计划处理。
- **低**：锦上添花。有空闲时间时处理。

## 如何记录新债务

1. 在上方表格中添加一行
2. 根据定义分配优先级
3. 填写 Owner（无 Owner 写 `ORPHAN`）
4. 如有关联计划，链接到 `docs/active/{版本}/{需求}/plan.md`
5. 解决后删除该行
