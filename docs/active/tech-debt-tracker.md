# 技术债务追踪

智能体在修改某个领域前，应先查看该领域是否有已知债务。完成任务后发现新的债务，应记录到此文件。

| 编号 | 领域     | 问题描述                                                         | 优先级 | 记录日期   | Owner  | 关联计划 |
| ---- | -------- | ---------------------------------------------------------------- | ------ | ---------- | ------ | -------- |
| TD1  | timeline | timeline.vue 使用 Options API，与项目 Composition API 风格不一致 | 低     | 2026-06-07 | ORPHAN | —        |
| TD2  | icons    | @iconify/vue 已安装但未使用，timeline 数据中 icon 字段未渲染     | 低     | 2026-06-07 | ORPHAN | —        |
| TD3  | layouts  | vite-plugin-vue-layouts peer dep 不兼容 vite 7 / vue-router 5    | 中     | 2026-06-07 | ORPHAN | —        |

## 优先级含义

- **紧急**：阻碍智能体有效工作或导致生产事故。应优先处理。
- **高**：降低质量评分，应在本迭代解决。遇到时应顺手修复。
- **中**：已知缺口，已有改进计划。按计划处理。
- **低**：锦上添花。有空闲时间时处理。

## 如何记录新债务

1. 在上方表格中添加一行
2. 根据定义分配优先级
3. 填写 Owner（无 Owner 写 `ORPHAN`）
4. 如有关联计划，链接到 `docs/active/{需求}/plan.md`
5. 解决后删除该行
