# 文档地图

这里保存项目维护所需的事实、决策和工作记录；访客阅读项目介绍请从根目录 [README](../README.md) 开始。

## 先看什么

| 目的                         | 文档                                      |
| ---------------------------- | ----------------------------------------- |
| 了解代码边界与目录职责       | [架构地图](../ARCHITECTURE.md)            |
| 了解页面与内容领域           | [业务领域](./DOMAINS.md)                  |
| 遵循长期工程信条             | [核心信条](./design-docs/core-beliefs.md) |
| 查看进行中的版本             | [活跃工作](./active/index.md)             |
| 查看尚未绑定版本的想法与草图 | [设计探索](./active/explorations/)        |
| 查阅已发布版本               | [版本归档](./archive/index.md)            |
| 查看自动生成的资料           | [生成文档](./generated/index.md)          |
| 处理安全问题                 | [安全策略](../SECURITY.md)                |

## 维护规则

- 代码、配置和验证结果优先；文档与事实冲突时及时回写。
- 每个活跃版本维护自己的需求、设计、证据和发布记录。
- 只有已发布且具备 `release.md` 的版本进入 `archive/`。
- `generated/` 中的文件由工具生成，不手工编辑。
